# 🎮 Simon Says Game

A fun memory-based game built with **HTML, CSS, and JavaScript**.  
The goal is to repeat the sequence of colors shown by the computer.  
Each round gets harder as the sequence grows longer!

---

## ✨ Features
- Interactive UI with colorful buttons
- Increasing difficulty with each round
- Simple, responsive design
- Pure JavaScript logic (no frameworks)

---

## 🚀 How to Play
1. Press any key to start.
2. Watch the sequence of colors flash.
3. Repeat the sequence by clicking the buttons.
4. Survive as long as you can — one mistake ends the game!

---

## 🛠️ Tech Stack
- HTML for structure
- CSS for styling
- JavaScript for game logic
